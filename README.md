# AmicSport ⚽

AmicSport es una plataforma premium para la gestión y reserva de partidos de fútbol, diseñada para ofrecer una experiencia fluida tanto a administradores como a jugadores.

## 🚀 Inicio Rápido

1. **Instalar dependencias**:
   ```bash
   npm install
   ```
2. **Configurar variables de entorno**:
   Crea un archivo `.env` con tus credenciales de Supabase:
   ```text
   EXPO_PUBLIC_SUPABASE_URL=tu_url
   EXPO_PUBLIC_SUPABASE_ANON_KEY=tu_key
   ```
3. **Iniciar la aplicación**:
   ```bash
   npx expo start
   ```

## 🛠 Tech Stack

*   **Frontend**: React Native + Expo (Router basado en archivos).
*   **Backend**: Supabase (Base de datos PostgreSQL + Auth + RLS).
*   **Maps**: Google Maps API integration.
*   **Iconos**: Lucide & Ionicons.
